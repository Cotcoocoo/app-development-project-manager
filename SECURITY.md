# Security Policy

## Supported versions

Security fixes are assessed for the latest version on the default branch.

## Reporting a vulnerability

Do **not** report suspected vulnerabilities through a public GitHub Issue.

After publishing this repository, enable GitHub private vulnerability reporting in the repository security settings and use that channel for reports. If that channel is not yet enabled, contact the repository maintainer through the private contact method listed in the repository profile with:

- a clear description of the issue;
- affected files or behavior;
- reproduction steps or a minimal proof of concept when safe to share;
- potential impact;
- suggested mitigation, if available.

Please avoid including secrets, tokens, personal data, or production data in the report.

## Disclosure

Maintainers will acknowledge a report, assess the impact, coordinate a fix where appropriate, and publish disclosure details only after a remediation plan is available. This repository provides project-management instructions and does not itself make security, compliance, or release-readiness guarantees.
