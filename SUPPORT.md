# Support

## Getting help

- Read [README.md](README.md) for scope, installation, and example prompts.
- Search existing GitHub Issues before opening a new one.
- Use the feature request form for reusable workflow ideas.
- Use the bug report form when the Skill produces an inconsistent, unsafe, or unclear workflow.

## Not a support channel for

- Secrets, credentials, private repositories, customer data, or internal project files.
- Urgent production incidents requiring a real-time response.
- Legal, medical, financial, security-certification, or compliance decisions.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
